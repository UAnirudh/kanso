# Accessibility gate: axe on the dashboard, account page and a generated workspace (T-012)

- Date: 2026-11-27
- Agent: codebuff
- Task: T-012
- Branch: `agent/a11y-gate`

## Goal

Turn accessibility from a manual review into a CI gate: axe scans the three guest-visible
surfaces at WCAG 2.0/2.1 A/AA and the Playwright job fails on serious or critical violations.
The defects the first runs found were fixed at the token and markup level, not suppressed.

## Changed

- `e2e/accessibility.spec.ts` (new) — two tests. One audits `/` (dashboard) and `/sign-in`; the
  other generates a real workspace with the local planner (no key in CI) and audits it. Uses
  `AxeBuilder().withTags(["wcag2a","wcag2aa","wcag21a","wcag21aa"])`, keeps only `serious` and
  `critical` violations, and fails with the rule id, impact and node targets. Moderate and minor
  findings stay in axe's report but do not gate yet.
- `package.json`, `package-lock.json` — `@axe-core/playwright@^4.14.1` as a devDependency only
  (27 lock lines, 0 vulnerabilities at install). ADR-13 records why a dependency is warranted.
- `app/globals.css` — `--color-mist-600` `#5f626b` → `#7f828d`, `--chrome-faint` `#6b6f7a` →
  `#8a8d98`; light `--s-muted` `#67707c` → `#4f5865`, light `--s-faint` `#9ba1aa` → `#656e79`,
  dark `--s-faint` `#71767f` → `#8b909a`; done-task title now uses `--s-muted`; pill text darkened
  (`#dc2626→#b91c1c`, `#ea580c→#9a3412`, `#2563eb→#1d4ed8`, `#64748b→#475569`).
- The same grey replacements in the app chrome: `app/dashboard/page.tsx`, `app/sign-in/page.tsx`,
  `app/metrics/page.tsx`, `app/not-found.tsx`, `app/error.tsx`, `components/dashboard/Forms.tsx`,
  `components/workspace/{AiPanel,Sidebar,HistoryDrawer,WorkspaceClient,dialogs,TopBar}.tsx`,
  `components/workspace/render/Surface.tsx`; "Saved" in the top bar is now `emerald-400` instead
  of `emerald-400/60`.
- `components/workspace/render/task-views.tsx` — removed the card's `aria-label` that omitted the
  visible priority/due text (WCAG 2.5.3) and put `<span className="sr-only">Open </span>` inside
  the title; the mark button is labelled `Mark done: <title>` so its visible text is contained.
- `ARCHITECTURE.md` — ADR-13 (gate level, the real defects that drove the token fixes, coverage
  limits). `IMPLEMENTATION_PLAN.md` — axe item checked. `README.md` — `test:e2e` row now says the
  suite includes axe. `agents/tasks.md` — T-012 row to `review`.

## Verified

- `npm run typecheck` → exit 0.
- `npm run test:e2e` → **6 passed (58.7s)**, exit 0: acceptance 28.8s / 6.6s / 2.8s (including the
  T-011 "What changes" diff assertions), axe 5.2s / 3.7s, security headers 2.3s.

- `npx playwright test e2e/accessibility.spec.ts` → **2 passed (20.7s)** after the fixes. The first

  `label-content-name-mismatch` on the task-card open and mark-done buttons.

  the same Linux/Node 22 combination CI uses.

- Keyboard order, focus management, zoom/reflow and screen-reader announcements remain manual.
