## Changed

  `npm ci` → `npm run typecheck` → `npm test` → `npm run build`. `permissions: contents: read`,
  a `concurrency` group that cancels superseded runs on the same ref, `timeout-minutes: 20`, and

### Why these steps and not more

`npm ci` rather than `install`: a manifest/lockfile mismatch is the documented way the Docker and
Render builds break (AGENTS.md §8), and it fails here in about a minute instead of inside an image
build. Node 22 because that is what `node:22-bookworm-slim` and Render run, and vitest 4 → vite 8
needs 22.12+. The Playwright suite is deliberately excluded — it needs
`npx playwright install chromium` plus a fresh database, and the ask was typecheck/tests/build.
